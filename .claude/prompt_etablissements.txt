Le fichier '~/pax/ressources/a_integrer_dans_db/academie_france.csv' contient la liste de toutes les academies en France.
Tu vas créer un script qui peuple la table academies avec ces données.

Le fichier '~/pax/ressources/a_integrer_dans_db/etablissements_aix_marseeille.csv' contient tous les établissements de l'académie d'Aix-Marseille.
Tu vas créer un script qui peuple la table des établissements avec ces données. La clé de cette table est l'UAI (colonne 1).

Sur la fenêtre de login, tu vas ajouter la possibilité de se créer un compte prof.
Il est impératif d'utiliser une adresse se terminant par @ac-aix-marseille.fr

Je voudrais que chaque élève, professeur et admin soit rattaché à un établissement.
Pour les utilisateurs déjà existants, rattache-les à l'établissement qui a l'UAI 0132401P (Collège Château Forbin)

A l'inscription, un professeur DOIT obligatoirement indiquer un établissement.
Il y a un champ de recherche où il peut taper sa commune, son code postal, son code UAI/RNE, ou le nom de son établissement (ou une partie seulement).
A partir des infos tapées, une liste d'établissements (50 au maximum) s'affiche, parmi lesquels il doit choisir. Une recherche plus précise doit réduire la liste des établissements.

Un professeur doit pouvoir gérer ses utilisateurs élèves. Par défaut, ils font partie du même établissement que leur professeur.
Un élève peut avoir plusieurs professeurs du même établissement.

Plusieurs élèves peuvent avoir les mêmes prénoms et noms s'ils ne sont pas dans le même établissement. Mais dans un établissement, il ne peut pas y avoir deux élèves avec le même couple prénom-nom

Un admin doit pouvoir gérer les utilisateurs du même établissement que lui : admins, professeurs et élèves.

Je voudrais que tu supprimes le rôle Inspecteur et que tu ajoutes le rôle super-admin : c'est l'admin de tous les admins, qui a accès à tous les établissements, tous les admins, profs et élèves de tous les établissements.
