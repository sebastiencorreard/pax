# Base de données
# 2.0.30 ne survit pas à python 3.13+ : son `FastIntFlag` ramasse

# symbole canonique — l'import de l'application s'arrête sur un TypeError avant
# même d'atteindre le premier routeur. Première version à publier une wheel
# `cp314` : 2.0.45.

# Les deux pilotes ne publient de wheel `cp314` qu'à partir de ces versions
# (asyncpg 0.31, psycopg2-binary 2.9.11). En dessous, pip retombe sur une
# compilation depuis les sources, qui s'arrête faute de `pg_config` — l'image
# `slim` n'embarque pas `libpq-dev`. C'est ce qui bloquait la montée de
# l'image de base vers python 3.14.
